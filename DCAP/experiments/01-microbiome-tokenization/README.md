# 01 — 마이크로바이옴 토큰화

**상태:** 합성 데이터 검증 완료 (실제 데이터 미적용)

## 질문

조성 자료(compositional data)인 마이크로바이옴 상대풍부도를 트랜스포머의
토큰 시퀀스로 바꾸는 가장 합리적인 방법은 무엇이고, 그렇게 얻은 표현이
평범한 베이스라인보다 나은가?

## 데이터

| 항목 | 값 |
|---|---|
| 출처 | curatedMetagenomicData (Bioconductor) — taxa 상대풍부도 + pathway 풍부도 |
| 접근 | 공개. `R/01_extract_cmd.R` 로 추출 |
| 합성 대체 | `src/make_synthetic.py` — 연구 간 배치효과와 질환 신호를 포함 |
| 아래 결과의 데이터 | 합성 (샘플 360, taxa 180, pathway 90, study 3) |

## 방법

**토큰화** — 상대풍부도 → pseudocount → CLR → 풍부도 내림차순 정렬.
CLR 로 폐쇄성(합=1)을 먼저 풀지 않으면 가짜 음의 상관이 그대로 모델에 들어갑니다.
값 인코딩은 세 논문의 방식을 `--value-mode` 로 갈아 끼울 수 있습니다
(`rank` = Geneformer, `bin` = scGPT, `cont` = scFoundation).

**세 가지 구성**

| 구성 | 내용 | 파일 |
|---|---|---|
| A | 변수 간 어텐션 — 마스킹 복원 자기지도 사전학습 | `src/pretrain_masked.py` |
| C | 모달리티 간 정렬 — taxa ↔ pathway 대조학습 | `src/crossmodal.py` |
| D | 계통수를 어텐션 마스크로 (같은 과끼리만 어텐션 허용) | `src/phylo.py`, `--use-phylo` |

**검증** — study 단위 `GroupKFold`. 사전학습의 train/val 분할도 study 단위로,
한 연구를 통째로 보류합니다. 표본 단위 분할은 배치효과를 학습해 AUC를 부풀립니다.

## 실행

```bash
export PYTHONPATH=src
bash run_all.sh
```

| 항목 | 값 |
|---|---|
| 시드 | 0 (모든 스크립트 `--seed 0`) |
| 사전학습 | 15 epoch · 2층 · d=64 · head 4 |
| 대조학습 | 8 epoch · batch 32 |
| 환경 | Python 3.12, torch 2.13 (CPU) |

## 결과

study 단위 GroupKFold (3 fold), 표본 360개 중 양성 146개(40.6%).

| 표현 | 분류기 | AUC | Brier | 보정기울기 |
|---|---|---|---|---|
| baseline_CLR | logreg | 0.633 | 0.323 | 0.08 |
| **baseline_CLR** | **gbdt** | **0.904** | **0.131** | 0.46 |
| baseline_CLR (taxa+pathway) | logreg | 0.619 | 0.324 | 0.08 |
| **baseline_CLR (taxa+pathway)** | **gbdt** | **0.907** | **0.132** | 0.50 |
| masked_pretrain_embedding | logreg | 0.765 | 0.208 | 0.35 |
| masked_pretrain_embedding | gbdt | 0.686 | 0.265 | 0.21 |
| crossmodal_embedding | logreg | 0.675 | 0.273 | 0.21 |
| crossmodal_embedding | gbdt | 0.590 | 0.313 | 0.10 |

대조학습 검증 retrieval 최고 0.042 (배치 내 우연 수준 ≈ 0.031).

## 해석

**부스팅 베이스라인이 사전학습 임베딩을 이겼습니다** (0.907 vs 0.765).
숨길 이유가 없는 결과이고, 특화 파운데이션 모델이 잘 만든 지도학습 베이스라인을
넘지 못한다는 최근 보고와 일치합니다. 이 규모(360 샘플, 2층)에서 자기지도
사전학습이 이기기를 기대할 근거가 애초에 없습니다.

**모든 보정 기울기가 1보다 한참 작습니다.** 전부 과신하고 있다는 뜻입니다.
AUC만 봤다면 "부스팅이 0.9니까 충분하다"고 결론냈을 텐데, 예측확률을 위험도로
쓰려면 이대로는 안 됩니다. 판별력과 보정을 함께 봐야 하는 이유입니다.

**모달리티 간 정렬은 보류 연구로 전이되지 않았습니다.** 학습 retrieval 은
0.33까지 올랐지만 검증은 우연 수준에 머물렀습니다. 두 모달리티의 정렬이
생물학적 대응이 아니라 **연구별 배치효과**를 학습했을 가능성이 큽니다.
표본 단위로 분할했다면 이 문제를 발견하지 못했을 것입니다.

## 한계

- 합성 데이터입니다. 어떤 생물학적 주장의 근거도 되지 않습니다.
- 2층 d=64 는 파운데이션 모델이 아닙니다. 구조 검증용 규모입니다.
- 순위 인코딩은 절대 풍부도를 버립니다. 의도된 손실이지만 손실입니다.
- `--phylo-level` 은 하이퍼파라미터입니다. `family` 기준 인접행렬 밀도 0.059.
- 대조학습 retrieval 은 배치 크기에 의존하므로 우연 수준과 함께 읽어야 합니다.
