# experiments

**실험 하나 = 디렉터리 하나.** 다른 실험을 import 하지 않습니다.
반년 뒤에 한 디렉터리만 복사해도 그대로 돌아가야 합니다.

## 새 실험 만들기

```bash
cp -r experiments/_template experiments/02-your-topic
```

## 디렉터리가 반드시 갖춰야 할 것

- `README.md` — 질문 / 데이터 / 방법 / **결과 표** / 한계
- `run_all.sh` — 합성 또는 공개 데이터로 끝까지 도는 명령 하나
- 결과 표에 **베이스라인이 함께** 들어 있을 것

## 번호 규칙

`NN-주제-슬러그` 형식. 번호는 시간 순서이지 중요도가 아닙니다.
폐기한 실험도 지우지 말고 README 맨 위에 `**상태: 폐기** — 이유` 를 적습니다.
막다른 길을 남기는 것도 기록입니다.
